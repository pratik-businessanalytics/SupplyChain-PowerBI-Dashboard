# Supply Chain Delivery Performance Dashboard

Power BI dashboard analyzing 200 shipments to identify critical delivery issues in North region.

## 📊 Key Insights
- **On-Time Delivery**: 70% overall | **North: 0%**, South/West: 100%
- **Total Shipments**: 200 | **Total Cost**: ₹1.1M 
- **Avg Delivery Days**: 5.8
